Как работает Attack Path Engine

Neo4j автоматически строит граф из данных сканирований:

  • Subdomain scan — нода Asset связывается с Domain
  • Port scan — нода Port связывается с Asset
  • Stealer / Breach — нода CredentialLeak связывается с Domain

Neo4j Browser UI доступен на порту 7474 (при запущенном docker-compose). Если Neo4j недоступен — раздел работает в режиме graceful degradation.
